# 元素煉金工坊 Elemental Alchemy Lab

原創煉金術元素落塊益智遊戲。落塊消行之上，疊加「元素相鄰反應」核心機制：
爆炸、蒸氣、植物、結晶、雷電、淨化——用連鎖煉金反應通關 12 個關卡並擊敗 Boss。

純前端、零後端、零付費 API、所有美術與音效皆程式生成。

## 安裝與啟動

```bash
npm install
npm run dev        # 開發模式（Vite，預設 http://localhost:5173）
npm run build      # 產出 dist/
npm run preview    # 預覽 build 結果
```

需求：Node 18+。支援 Chrome / Edge / Firefox / Safari（基本）。

## 操作

| 按鍵 | 動作 |
|---|---|
| ← → 或 A D | 左右移動（支援按住連續移動 DAS/ARR） |
| ↑ 或 W | 順時針旋轉（含簡化 wall kick） |
| Z | 逆時針旋轉 |
| ↓ 或 S | 加速下落 |
| Space | 瞬間落下（立即鎖定） |
| C | 暫存方塊（每次落塊限一次） |
| P / Esc | 暫停（計時與下落完全停止） |

手機／平板：畫面下方有觸控按鈕（coarse pointer 自動顯示），橫向優先。

## 元素反應表

**雙元素**（上下左右相鄰即反應）：

| 組合 | 反應 | 效果 |
|---|---|---|
| 火＋水 | 蒸氣 | 清除反應格＋各自上方最多 2 格（岩石阻擋） |
| 水＋土 | 生長 | 生成植物並蔓延；3 株相連整群綻放 |
| 火＋風 | 火焰風暴 | 十字延伸 2 格，遇岩石停止 |
| 土＋風 | 沙暴 | 推動同行方塊一格；推不動凝為沙塵 |
| 火＋土 | 熔岩 | 生成熔岩，每反應階段熔化下方一格×3 |
| 水＋風 | 冰霜 | 周圍最多 4 格化為冰晶（被波及即碎裂加分） |
| 土＋光 | 生命晶石 | 晶石被消除時回復大量能量 |
| 水＋光 | 聖泉 | 淨化附近暗元素與腐蝕；無目標則轉能量 |
| 風＋光 | 雷電 | 劈碎最高堆疊的至多 3 格 |
| 火＋暗 | 詛咒火焰 | 5×5 大範圍清除，殘留 1–2 個腐蝕 |
| 土＋暗 | 腐蝕 | 附近最多 3 格轉為暗元素 |
| 光＋暗 | 虛空淨化 | 清除整行＋整列（最高優先） |

**三元素**（優先於雙元素）：超熱蒸氣（火水風）、世界樹（水土光）、火山災變（火土暗）、極光風暴（水風光）、荒蕪（土風暗）。

**同元素共鳴**：4+ 相連清除；5–6 生成元素核心；7+ 生成強化核心。
核心效果：火＝3×3 爆炸、水＝清直列、土＝清橫行、風＝隨機散射、光＝清所有暗、暗＝吞噬一種元素。

## 已知限制

- 關卡進行中不存棋盤快照（離開關卡即重來；關卡完成進度會存）
- 反應非常頻繁是設計特性：4 基礎元素兩兩皆可反應，堆高消行比傳統落塊難，消行目標已據此調低
- 音樂為極簡合成 pad，非完整配樂
- 成就欄位已預留（存檔結構），第一版未實作成就清單

## 架構

```
src/
  config.js            全域常數（單一正本）
  core/    Game(session 狀態機) · GameLoop=rAF in main · EventBus · Random(種子)
  board/   Board(資料) · Piece(旋轉/kick) · PieceQueue(7-bag+權重元素)
  alchemy/ ReactionResolver(掃描/保留/連鎖) · ReactionEffects(效果+hitCell 唯一清除入口)
  systems/ Score · Spell · Boss · Level(目標) · Relic · Save · Audio · Input
  data/    elements · reactions · pieces · spells · relics · levels · bosses（全資料驅動）
  ui/      BoardRenderer(Canvas+粒子) · HUD · Screens · TutorialSystem
  styles/  main · game · panels · responsive
```
