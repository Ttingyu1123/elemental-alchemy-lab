# 元素煉金工坊 Elemental Alchemy Lab

原創煉金術元素落塊益智遊戲。落塊消行之上，疊加「元素相鄰反應」核心機制：
爆炸、蒸氣、植物、結晶、雷電、淨化——用連鎖煉金反應通關 12 個關卡並擊敗 Boss。

純前端、零後端、零付費 API、所有美術與音效皆程式生成。

**線上遊玩**：https://game-alchemy.tingyudeco.com/（GitHub Pages，main 分支根目錄直接服務——所有模組皆相對路徑 import，無需 build）

## 安裝與啟動

```bash
npm install
npm run dev        # 開發模式（Vite，預設 http://localhost:5173）
npm run build      # 產出 dist/
npm run preview    # 預覽 build 結果
```

需求：Node 18+。支援 Chrome / Edge / Firefox / Safari（基本）。

## 核心規則：化合物穩定性

**同一拼塊內的元素彼此穩定**——不互相反應、也不自體共鳴。反應只在「拼塊落地後與場上既有方塊相鄰」時發生，法術轉化或效果生成的新格子則不受限。這讓堆疊成行變得可規劃：反應是你主動觸發的工具，不是隨機災難。

**反應預覽**：幽靈落點若會觸發反應，相關格子會以該反應的顏色**脈動外框**標示；會湊成共鳴的格子以白色虛線框標示。落子前就能看見後果。

## 元素反應表

**雙元素**（上下左右相鄰即反應）：

| 組合 | 反應 | 效果 |
|---|---|---|
| 火＋水 | 蒸氣 | 清除反應格＋各自上方最多 2 格（岩石阻擋） |
| 水＋土 | 生長 | 生成植物並蔓延；3 株相連整群綻放 |
| 火＋風 | 火焰風暴 | 十字延伸 2 格，遇岩石停止 |
| 土＋風 | 沙暴 | 推動同行方塊一格；推不動凝為沙塵 |
| 火＋土 | 熔岩 | 生成熔岩，每反應階段熔化下方一格×3 |
| 水＋風 | 冰霜 | 周圍最多 4 格化為冰晶（被波及即碎裂加分） |
| 土＋光 | 生命晶石 | 晶石被消除時回復大量能量 |
| 水＋光 | 聖泉 | 淨化附近暗元素與腐蝕；無目標則轉能量 |
| 風＋光 | 雷電 | 劈碎最高堆疊的至多 3 格 |
| 火＋暗 | 詛咒火焰 | 5×5 大範圍清除，殘留 1–2 個腐蝕 |
| 土＋暗 | 腐蝕 | 附近最多 3 格轉為暗元素 |
| 光＋暗 | 虛空淨化 | 清除整行＋整列（最高優先） |

**三元素**（優先於雙元素）：超熱蒸氣（火水風）、世界樹（水土光）、火山災變（火土暗）、極光風暴（水風光）、荒蕪（土風暗）。

**同元素共鳴**：4+ 相連清除；5–6 生成元素核心；7+ 生成強化核心。
核心效果：火＝3×3 爆炸、水＝清直列、土＝清橫行、風＝隨機散射、光＝清所有暗、暗＝吞噬一種元素。

## 已完成功能

- 10×20 棋盤＋4 隱藏生成列；資料層與 Canvas 渲染分離
- 7 種原創拼塊、7-bag、幽靈落點、3 格預覽、暫存、lock delay（限次重置防無限旋轉）
- 12 種雙元素＋5 種三元素反應，資料驅動反應解析器（優先序＋格子保留＋連鎖上限 30）
- 化合物穩定性規則（同拼塊不自反應）＋落點反應預覽＋連鎖快轉
- 元素 pity：反應目標所需元素連 3 塊未出現時強制補給
- 同元素共鳴（BFS）＋六種元素核心
- 8 種特殊方塊：萬能元素、炸裂符文、鎖鏈（兩擊）、岩石／不可破壞岩石、腐蝕（會擴散）、冰封（破冰兩段）、不穩定藥劑（倒數）、金色元素
- 5 種法術（能量制、目標選擇模式、賢者之石每關一次）
- 連鎖倍率（×1 → ×8 上限）、浮動文字、反應紀錄
- 12 關卡（教學→元素逐步解鎖→步數限制→Boss）＋星級評價
- Boss「腐化煉金魔像」：4 階段、依落塊回合施放技能、反應傷害結算
- 8 種遺物（過關三選一，資料驅動 modifiers）
- 無限模式（加速、元素逐步解鎖、五項紀錄）
- 12 步互動教學（可略過、完成狀態存檔、中斷後從原步驟續播）
- 元素圖鑑＋反應圖鑑＋成就頁（未發現顯示剪影、首次發現 toast）
- 12 種成就（事件驅動解鎖、累計進度、解鎖 toast）
- **關卡中途存檔**：每次生成新拼塊自動建立檢查點（棋盤、佇列、暫存、分數、能量、步數、Boss 狀態、RNG 種子狀態）；重新整理或關頁後從主選單「繼續遊戲（進行中）」原地續玩，續玩後的拼塊序列與原局完全一致
- localStorage 存檔（saveVersion 2、v1 自動遷移、損壞回退、二次確認清除）
- Web Audio 合成音效（13 種）＋生成式背景音樂（Am–F–C–G 循環：pad、bass、琶音、星塵閃音，單一 lookahead 排程器，關閉即停止產生節點）
- 消行溶解動畫（方塊縮小淡出殘影＋金塵粒子；資料即時移除，殘影純視覺）
- 響應式（桌面 / 平板 / 手機直橫向）、觸控按鈕、aria-label、降低特效模式、圖示不只靠顏色

## 已知限制

- 4 基礎元素兩兩皆可反應，消行仍比傳統落塊難——穩定性規則＋預覽讓它可規劃，消行目標已據此調低
- 星級門檻以隨機 bot 基準校準，尚未經人工全關卡 playtest 微調
- 中途存檔只存「穩定檢查點」（每次生成新拼塊時）：解析連鎖進行中關頁，會回到該連鎖開始前的狀態
- 背景音樂為程式生成循環，非人工編曲配樂

```
  core/    Game(session 狀態機) · GameLoop=rAF in main · EventBus · Random(種子)

  data/    elements · reactions · pieces · spells · relics · levels · bosses（全資料驅動）
  ui/      BoardRenderer(Canvas+粒子) · HUD · Screens · TutorialSystem
  styles/  main · game · panels · responsive
```
